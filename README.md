"Fix branch" column links each game to the `games/*` branches (based on NullMoth v2.5.4) it needs; the branches are
described in `overlay/UPSTREAM-CANDIDATES-GAMES.md` on `dev`. Generated by the test project's `gamesite/pages.sh`.
